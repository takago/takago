# Daisuke TAKAGO

**Associate Professor, Department of Information Engineering**  
Kanazawa Institute of Technology, Japan

Welcome to **TAKAGO Lab.** — a collection of open-source projects for learning, experimentation, and everyday computing.

I develop software across UNIX/Linux, embedded systems, generative AI, and practical desktop tools. My focus is on building approachable systems that help people understand computing through hands-on exploration.

## Projects

### Operating Systems & Embedded Computing

**[PicoNIX](https://github.com/takago/PicoNIX)**  
A compact UNIX-like operating system for the Raspberry Pi Pico (RP2040). Built for hands-on exploration of processes, file systems, device I/O, networking, and operating-system internals.

### Generative AI & Content Creation

**[NarrationAutomata](https://github.com/takago/NarrationAutomata)**  
Automatically transforms PDF slides into narrated explanatory videos with subtitles and visual focus, using AI-powered tools.

**[EzRender](https://github.com/takago/EzRender)**  
A headless 3D rendering tool for GLB and OBJ models, with command-line control over viewpoints and image output.

### Linux Desktop & Networking

**[WiFi-BSSID-Manager](https://github.com/takago/WiFi-BSSID-Manager)**  
A Linux system-tray utility that pins the current Wi-Fi access point or clears saved BSSID restrictions through the NetworkManager D-Bus API.

**[proxy_switcher](https://github.com/takago/proxy_switcher)**  
A system-tray utility for viewing and switching proxy settings on GNOME, MATE, and Cinnamon desktops.

**[on_screen_messenger](https://github.com/takago/on_screen_messenger)**  
A lightweight utility for displaying messages on the desktop.

### Document Processing

**[PDF-Compressor](https://github.com/takago/PDF-Compressor)**  
A web application for reducing PDF file sizes by recompressing embedded images, with drag-and-drop uploads and batch processing.
